## Image Specifications

- **Format:** JPG or PNG
- **Recommended Size:** 800-1200px width
- **Quality:** High resolution (for web display)
- **Aspect Ratio:** Maintain original proportions from PDF

## How to Extract Images

1. Open the Arabic Company Profile PDF
2. Navigate to the specified page number
3. Use a PDF tool (Adobe Acrobat, PDF-XChange Editor, or online tools) to extract the image
4. Crop the image to remove any borders or text overlays
5. Save with the exact filename listed above
6. Place all images in this folder: `assets/images/construction/`

## Fallback Images

If an image is not found, the page will automatically use fallback images from the main `assets/images/` folder. However, for the best design match, please extract and use the exact images from the PDF.

## Notes

- All images should maintain the light beige background color scheme (#F8F7F0)
- Images should be professional construction/workplace photos
- Ensure images are optimized for web (compressed but high quality)
